## Run locally

```
npm install
npm run dev
```

Open the local address Vite prints (normally http://localhost:5173).

## Verify the build

```
npm run check
npm run build
npm run preview
```

`npm run check` runs the TypeScript compiler with no output (`tsc --noEmit`).
`npm run build` type-checks and then produces the `dist` folder.
`npm run preview` serves that `dist` folder locally so you can test the app
the same way it will behave once deployed.

## PWA test

1. Run `npm run build` then `npm run preview` and open the preview URL.
2. Reload the page once while online so the service worker installs.
3. Open DevTools → Application → Manifest and confirm it has no errors, both
   icons load, and the service worker shows as activated.
4. Open DevTools → Network and switch to **Offline**.
5. Reload the page — the app shell should still load from the cache, and the
   "Live test signal" card should switch to "Offline mode".
6. Create a note, refresh again, and confirm it is still there (it is stored
   in `localStorage`, separately from the cached shell).
7. Switch Network back to **Online**, reload once, and confirm the card
   switches back to "Network available".

## Deploying to GitHub Pages

This project is configured for a GitHub **project** page (i.e. a repository
named `offline-notes-lab` served at
`https://<your-username>.github.io/offline-notes-lab/`):

1. Push this project to a GitHub repository named `offline-notes-lab`.
2. In the repo, go to **Settings → Pages** and set the source to **GitHub
   Actions**, or use the `gh-pages` package / a simple Actions workflow that
   runs `npm run build` and publishes the `dist` folder.
3. If you rename the repository, or deploy to a root-level
   `<your-username>.github.io` repository instead, update the `base` value
   in `vite.config.ts` to match (use `base: "/"` for a root deployment).
4. After deployment, open the public URL, reload once online, then repeat
   the offline test above. Service workers are scoped to the exact URL they
   are served from, so re-test after any change to the deployment path.
5. Update the deployed URL below once it is live:

   **Deployed URL:** _add your GitHub Pages link here_

## Project structure

| Path | Purpose |
| --- | --- |
| `src/main.tsx` | Starts the React application and registers the service worker. |
| `src/App.tsx` | Contains the top-level component. |
| `src/index.css` | Contains global styles. |
| `src/pages/Home.tsx` | Contains the workshop interface. |
| `public/manifest.webmanifest` | Describes the installable web application. |
| `public/sw.js` | Caches files and provides an offline fallback. |
| `package.json` | Records scripts and dependencies. |

Do not edit the `dist` folder by hand — it is generated by `npm run build`.
